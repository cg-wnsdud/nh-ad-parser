# ETLwithLLM 연동 방향 검토 요청

## 요청드리는 결정

농협 DLA/OCR을 사용하면서 광고 파싱 후처리를 연결하는 방법을 세 후보로 구현했습니다.
현재 단계는 방향 결정용이며 농협 반입 완성본은 아닙니다.

### 추천

1. **A안(농협 내부 별도 프로세스에서 ETL HTTP API 호출)을 기준선으로 유지**합니다.
2. AgileSoDA에 `transform()`의 호출·결과 저장 계약을 확인하고, 가능하면 **B안**을
   운영 후보로 선택합니다.
3. `CUSTOMIZE`는 전처리 뒤 DLA가 이어진다는 답을 받기 전에는 선택하지 않습니다.
4. Knowledge Lake가 최상위 호출자라는 요구가 있을 때만 현재 저장소의 선택적
   `kl_api` 진입점을 운영 범위로 포함합니다.

## 후보별 의미

| 후보 | 하는 일 | 결정에 필요한 답 |
|---|---|---|
| A 농협 내부 별도 프로세스/API | ETL 컨테이너 밖의 우리 실행기가 `/etl/auto/start`로 DLA를 요청하고 JSON을 받아 후처리 | 우리 실행기를 둘 농협 내부 위치 |
| B transform | ETL의 DLA 완료 뒤 같은 플랫폼 프로세스에서 우리 파이프라인 실행 | transform 호출 시점·입출력 경로·의존성 설치 방법 |
| C CUSTOMIZE | extract 훅의 실제 인자와 후속 동작만 관찰 | 외부 `customize` 지원 여부, extract 뒤 DLA 연결 방법 |
| KL Custom Parser | 광고 파일 접수·UUID polling·ZIP 계약 제공 | 최상위 업무 흐름이 KL인지, 광고 접수 URL을 별도 등록할 수 있는지 |

`외부 API`에서 외부는 인터넷이나 회사망이 아니라 **ETLwithLLM 컨테이너 외부이면서
농협 폐쇄망 내부인 별도 프로세스**를 의미합니다.

현재 저장소에는 광고용 `/ad/parsing`·UUID polling·결과 ZIP을 제공하는 선택적
`kl_api`를 실행 가능하게 이식했습니다. 일반 문서 `/parsing`은 RAG/KL exporter가 현재
광고 저장소 범위에 없으므로 구현하지 않았습니다. 또한 A안은 농협 DLA로 PaddleX를
대체하지만, 분류·보조 판독·템플릿 라벨링의 Gemma 경로는 남으므로 농협 LLM/VLM
연동 방식도 결정이 필요합니다.

주의할 점은 농협 제공 AWX 원본 예제에서 확인되는 접수 URL은 `POST /parsing`이고,
`POST /ad/parsing`은 이전 광고 프로토타입이 추가한 URL이라는 것입니다. KL에서 이 URL을
별도로 등록할 수 있는지 확인되기 전에는 KL 광고 연동 완료로 볼 수 없습니다.

## 문서에서 확인된 결정적 근거

- 외부 API p.29의 `extract_type` 공개값은 `all`, `dla`, `parser`뿐입니다.
- p.53 내부 `CUSTOMIZE` 분기는 `extract()`만 호출하고 `dla_task()`를 호출하지 않습니다.
- p.54 `transform()`은 `dla_result_path`를 받으므로 DLA 결과 후처리 위치라는 점은
  확인됩니다.
- `implements/api/`는 ETL 서버에 선택적인 API를 추가하는 기능이며, KL Custom Parser
  API와 자동으로 연결되지 않습니다.

## 공급사에 확인할 질문

1. 외부 `prj_config.extract_type`에서 `customize`를 지원합니까?
2. `CustomExtension.extract()` 완료 후 기본 DLA를 이어 실행하는 공식 API가 있습니까?
3. `extract_type=dla`일 때 `transform()`은 항상 호출됩니까?
4. `dla_result_path`는 파일입니까, 디렉터리입니까? Default JSON 위치는 어디입니까?
5. `transform()` 산출물을 어느 경로에 써야 ETL 결과 목록·callback에 포함됩니까?
6. `CustomExtension` import 경로와 구현체 로딩 규칙을 포함한 원본 템플릿을 받을 수
   있습니까?
7. ETL 이미지에 프로젝트 wheel과 외부 Python/system 의존성을 설치하는 공식 절차는
   무엇입니까?
8. DLA 이후 문서 분류·보조 판독·템플릿 라벨링에 사용할 농협 내부 LLM/VLM
   엔드포인트와 요청 규격을 제공받을 수 있습니까?
9. Knowledge Lake에 광고 파서 URL을 `/ad/parsing`으로 별도 등록할 수 있습니까? 불가하면
   광고 전용 배포의 `/parsing`이 광고 작업을 받도록 구성해도 됩니까?
10. A안 별도 서비스를 실행할 서버/컨테이너와 Python 버전, 오프라인 의존성 반입 방식은
    무엇입니까?
